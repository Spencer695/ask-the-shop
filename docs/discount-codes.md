# Discount codes and promotions

## Current codes
WELCOME10 gives 10% off your first order when you sign up for our email list. FALL15 gives 15% off everything through October 31. FREESHIP gives free standard shipping with no minimum and is sent to text message subscribers.

## Code rules
You can use one discount code per order. Codes can't be used on gift cards and can't be combined with each other.

## Forgot to use a code
We can't add a code to an order after it has been placed. If you forgot your code, contact us within 1 hour of ordering and we will cancel the order so you can place it again with the code.
